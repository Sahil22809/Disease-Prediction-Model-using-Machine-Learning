# 🧠 Disease Predictor Using Machine Learning

A Machine Learning based desktop application that predicts diseases based on user-input symptoms. The system uses three different algorithms—**Decision Tree**, **Random Forest**, and **Naive Bayes**—to provide reliable disease predictions.

## 🩺 Overview

This project provides a user-friendly interface for predicting diseases from symptoms. Users can select up to five symptoms, and the application will predict the most probable diseases using three different machine learning models.

### 👨‍⚕️ Features
- It certainly has hover effect on the buttons
- Predicts diseases based on symptoms
- Uses three ML models:
  - Decision Tree
  - Random Forest
  - Naive Bayes
- Displays three prediction results (one from each algorithm)
- Easy-to-use GUI developed with **Tkinter**
- Interactive dropdown menus for symptom selection
